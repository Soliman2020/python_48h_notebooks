# Python 48H — Student Notebooks

**Course creator/Instructor:** Mohamed Hamed Soliman

Welcome to the **Python 48H Student Pack**. This collection of Google Colab notebooks is designed for professionals, career changers, and beginners from different backgrounds who want to build practical Python skills step by step.

The complete course is planned as **10 session notebooks covering 12 learning sessions**. Sessions 01–10 are currently available, with focused Session 05 expansion notebooks and instructor solution notebooks provided separately.

The notebooks combine clear explanations, runnable examples, and practice activities. No previous programming experience is required.

## Course sequence

Study the available notebooks in the following order. Session 05 includes the main functions notebook plus focused expansion notebooks. Sessions 08–10 extend the course into practical data analysis, classes, and decorators:

1. **Session 01 — Getting Started, Variables, Types & Calculations**  
   Learn Python basics, variables, data types, values, operators, and calculations.

2. **Session 02 — Strings, Comparisons & Decisions**  
   Work with text, string methods, comparisons, Boolean expressions, and conditional logic using `if`, `elif`, and `else`.

3. **Session 03 — Collections: Lists, Tuples, Sets & Dictionaries**  
   Organize and manipulate groups of data using Python’s core collection types.

4. **Session 04 — Repetition, Loops & Processing Records**  
   Use `for` and `while` loops to repeat tasks and process records systematically.

5. **Session 05 — Functions, Reuse & Modules**  
   Define reusable functions, organize code into modules, and build a guided mini-project.

   Focused expansions cover lambda examples, libraries, and small test cases.

6. **Session 06 — Errors, Debugging & Small Tests**  
   Read error messages, debug programs systematically, and write small tests.

7. **Session 07 — Working with TXT, CSV & JSON Files**  
   Read, write, and process common text and structured data files.

8. **Session 08 — Pandas Tabular Data for Beginners**  
   Inspect, filter, summarise, and explore tabular data with Pandas.

9. **Session 09 — Pandas Cleaning, Combining & Reporting**  
   Inspect messy data, handle missing values, use `concat()` and `merge()`, validate joins, and produce checked reports.

10. **Session 10 — Classes and Decorators**  
    Model work items with classes and add reusable logging, validation, timing, and caching behavior with decorators.

## How to use the notebooks

### Recommended: Google Colab

1. Open the notebook you want to study.
2. Click the **Open in Colab** button in the notebook’s top cell.
3. In Google Colab, make your own copy of the notebook.
4. Continue reading, editing, and running the exercises in your copied notebook.
5. Alternatively, open [Google Colab](https://colab.research.google.com/) and select **File → Open notebook → GitHub**, or upload a notebook from your computer.
6. Read each explanation in order and run the code cells from top to bottom.
7. Change the examples and run them again to test your understanding.
8. Complete any exercises before moving to the next session.

### Other options

The notebooks can also be opened with Jupyter Notebook or JupyterLab on a local Python installation. Google Colab is recommended because it runs in a browser and normally requires no local setup.

## Learning approach

- Follow the sessions in sequence; later notebooks build on earlier concepts.
- Run the examples instead of only reading them.
- Experiment by changing values, conditions, and data.
- When an error appears, read the message and identify the line that caused it.
- Practice with examples related to your own profession or daily work.
- Keep your own notes and revisit earlier exercises when needed.
